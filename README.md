# SQL Management Agent
The SQL Management Connector facilitates the seamless synchronization of diverse data types with SQL Server databases, utilizing the capabilities of Microsoft Identity Manager 2016 (MIM 2016) or Forefront Identity Manager 2010 R2 (FIM 2010).

## Key Features:
* Comprehensive support for full and incremental data imports
* Efficient delta and full data exports
* Ability to retain and recover deleted data entries (softdeletes)
* Execution of pre- and post-import/export stored procedures
* Highly adaptable schema dynamically generated from database table definitions
* Schema refresh functionality for schema rediscovery
* Customizable schema structure through XML configuration
